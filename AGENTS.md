# Agent Instructions

Personal website and blog built with Astro, Tailwind CSS, and TypeScript. Content is markdown-first and lives in `src/content/`. See [`README.md`](README.md) for structure and commands.

Shared agent instructions and skills live in [`.agents/`](.agents/README.md).

## Always follow

- **British English**: all content and user-facing text must use British English. Follow [`.agents/instructions/british-english.md`](.agents/instructions/british-english.md).

## Project notes

- **Contact form**: submits to Formspree because GitHub Pages is static. Read [`.agents/instructions/contact-form.md`](.agents/instructions/contact-form.md) before changing `src/pages/contact.astro`.
