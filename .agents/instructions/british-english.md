# British English

All written content on this site uses **British English**. This applies to anything a reader will see, including:

- Markdown in `src/content/` (blog posts and projects)
- Visible text in `src/` (page copy, headings, buttons, navigation, alt text, meta descriptions)
- Documentation such as `README.md`

## Spelling

| Use (British) | Not (American) |
| --- | --- |
| colour, favour, behaviour | color, favor, behavior |
| organise, recognise, analyse | organize, recognize, analyze |
| centre, metre, theatre | center, meter, theater |
| travelled, modelling, labelled | traveled, modeling, labeled |
| catalogue, dialogue | catalog, dialog |
| defence, offence | defense, offense |
| grey, aluminium, tyre | gray, aluminum, tire |
| programme (schedule/scheme) | program |

Use `-ise` rather than `-ize` endings (organise, realise, prioritise).

"Program" is still correct for computer programs.

Nouns and verbs are spelled differently: "licence" and "practice" are nouns, "license" and "practise" are verbs (e.g. "a driving licence", "licensed to practise").

## Vocabulary and style

- Prefer British terms: "maths", "autumn", "holiday", "mobile phone", "postcode".
- Write dates as `23 November 2026`, not `November 23, 2026`.
- Use single quotation marks for quotes ('like this'), with double marks for a quote inside a quote.

## Do not change

- **Code**: variable names, CSS properties and classes (`color`, `text-center`), Tailwind config keys, framework APIs, file names, and URLs.
- **Proper nouns and titles**: names of organisations, products, and published papers or books keep their original spelling.
- **Direct quotes**: keep the spelling of the source.

When editing existing text, fix American spellings in the parts you touch. Do not rewrite unrelated content just to change spelling unless asked.
